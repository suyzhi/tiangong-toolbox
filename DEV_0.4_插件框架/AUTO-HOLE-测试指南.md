# 自动打孔系列 · 测试指南

这份文档是给你**上手测**用的。三步一组的操作，每一步都写了"应该看到什么"。看到的不一样就照最后一节的表查。

---

## 0. 准备（只做一次）

插件已经注册到你机器上了，指向：

```
DEV_0.4_插件框架\build\autohole-5\TianGongCadSuite.dll
```

1. **完全退出天工CAD**（保存工作）。已打开的 CAD 用的是内存里的旧版本，不重启不生效。
2. 启动天工CAD。
3. 打开任意**装配（.asm）**。
4. 功能区找「**插件（加载项）→ 功能**」，应该能看到 8 个命令，其中三个是新的：

| 命令 | 名字 |
|---|---|
| 6 | 自动打孔 |
| 7 | 批量排孔 |
| 8 | 配孔检查 |

> 如果看不到命令：右键功能区空白处，确认「天工工具箱 DEV」这个选项卡被勾上。

**建议先自己造个测试装配**：两块 100×100×10 的板，平行装配、相距 20mm；在下面那块板上先手动打一个 Φ8.5 的孔（天工原生孔命令，M10 底孔）。这样三个功能都能测。

## 1. 命令 6「自动打孔」——照着一个或多个已有的孔打孔

> **没有模式切换。** 点**圆边**就是加一个参考孔，点**平面**就是加一个打孔面。顺序随意，边和面随时都能点。

### 操作

1. 点「自动打孔」，弹出一个窗口。
2. **点下面那块板上 Φ8.5 孔的圆形边线**（点孔口那个圆）。
   - 第①行变成：`Φ8.5 ×1　（共 1 个）`
3. **再点另一个大小不同的孔**（比如 Φ13.5 的孔）。
   - 第①行变成：`Φ8.5 ×1、Φ13.5 ×1　（共 2 个）`
   - **一次可以选任意多个、任意大小组合的参考孔。**
4. **点上面那块板的下表面**（要靠在一起的那个面）。
   - 第②行变成：`已选 1 个面`，选中的面**高亮成深天蓝**
5. 第③行显示映射关系：
   > 将打 2 个孔：
   > 　　Φ8.5 → 圆柱沉孔 Φ11　沉孔Φ18 深11　(M10)　贯通　×1
   > 　　Φ13.5 → 螺纹孔 Φ10.2　(M12)　贯通　×1
6. 点蓝色的「**开始打孔**」按钮。

### 应该看到

- 弹窗：`共打孔 2 个… 参考孔 2 个，打孔面 1 个`
- 目标零件上出现两个**规格各自对应**的孔，**参照件一点没变**。

### 重点验证这几条

- [ ] **一次能选多个参考孔**，大小不同也行
- [ ] 第①行按直径归并显示成 `Φ8.5 ×1、Φ13.5 ×1`
- [ ] 第③行**按每个参考孔分别列出**对应的孔型规格
- [ ] **不用切模式**：圆边和平面随时都能点
- [ ] 选中的面和参考孔都**高亮**了
- [ ] 打完后**参照件没被改动**
- [ ] 按 **Esc** 或右键能关掉窗口

### 故意试试边界

- 点一个**不是孔**的边（比如板的轮廓边）→ 应该提示"选中的边不是圆孔"
- 同一个孔点两次 → 提示"这个孔已经选过了"；同一个面点两次 → 提示"这个面已经选过了"
- 选两个**不平行**的零件上的面 → 应该明确报"参考孔的轴线与打孔面几乎平行"
- **让某个参考孔的投影落到打孔面外面**（比如选一块小很多的板当打孔面）→ 那个孔应该被**跳过**，结果里写"跳过 N 个（投影不落在所选面上）"，而不是硬打一个跑到材料外面的孔
- **在第一层零件上点孔** → 应该选到第一层的孔，**不能"透过"它选到后面零件的边线**（这是 `LocateFrontToBack` 的作用）

### 手动调孔参数（③ 区）

自动推出来的规格不一定是你想要的，下面这一区可以随便改。

1. 在①的列表里**点一行**（比如 `Φ9 ×2　圆柱沉孔 Φ9 沉孔Φ14.5 深8.6 (M8) 贯通`）
2. 下面③区就会载入这一组孔的参数
3. 改任意字段：
   - **孔型**：通孔 / 螺纹孔 / 圆柱沉孔 / 锥形沉孔 —— 换了孔型，③区会**只显示该孔型需要的字段**
   - **规格**：M3–M20 或「自定义」—— 换规格会**自动重填**下面的默认尺寸，然后你还可以继续手改
   - **孔径**：主孔直径
   - **深度**：勾「贯通」就是打通；**去掉勾**填数字就是打**盲孔**（比如填 5 = 深 5mm）
   - **沉孔Φ / 沉孔深**：只有圆柱沉孔时出现
   - **锥孔Φ / 锥角°**：只有锥形沉孔时出现
   - **螺纹深**：只有螺纹孔时出现；**填 0 = 跟孔深一样**
4. 改完列表那一行会立刻更新，③区下面的预览行也会跟着变
5. 点「开始打孔」

**重点验证**

- [ ] 点列表换行，③区字段跟着换
- [ ] 换孔型时，③区**只显示该孔型需要的字段**（选通孔时看不到沉孔Φ）
- [ ] 换规格会**自动重填**默认尺寸，重填后还能继续手改
- [ ] 勾「贯通」时深度框变灰
- [ ] 去掉「贯通」勾、填 5 → 打出的是**盲孔**（深度 5mm），不是通孔
- [ ] 改一组孔的参数，**只影响这一组**，不影响另一组

## 2. 命令 7「批量排孔」——一个面上排一排孔

### 操作

1. 点「批量排孔」。
2. **点要打孔的那个面**。
   - 第①行变成：`已选面，自动取最长边（100mm）` ← 方向**自动**取该面最长的直边
3. 选排布方式（默认「沿边等分」），填**孔数**和**边距**。
   - 第③行实时预览：`沿 100mm 等分排 4 孔，边距 10mm`
4. 选**孔型**（通孔/螺纹孔/圆柱沉孔/锥形沉孔）和**规格**（M3–M20）。
5. 点「开始打孔」。

### 三种排布方式都试一遍

| 方式 | 填什么 | 预期 |
|---|---|---|
| **沿边等分** | 孔数 4、边距 10 | 首末孔正好落在距两端 10mm，中间均分 |
| **沿边定距** | 间距 30、边距 10 | 每 30mm 一个，预览会告诉你一共几个 |
| **圆周均布** | 孔数 6 | **第②步变成"再点一条圆形边线"**，点了以后在 R 的圆上均布 6 个 |

### 腰孔

勾上「**腰孔**」，填总长（默认 30mm）。会打出长圆孔而不是圆孔。

> 腰孔只在**沿线**模式可用；圆周模式会忽略这个勾。

### 应该看到

- 打完后每个孔是**一个独立的孔特征**（不是阵列特征）—— 这是底层 API 的限制，不影响使用
- 弹窗里有`实际孔特征：N 个`

### 重点验证

- [ ] 不选方向边时，**方向是自动取的**，且预览里的长度等于该面最长边
- [ ] 改孔数/间距时，**第③行预览实时变**
- [ ] 边距填太大（比如边距 60、长度 100）→ 应该报"边距过大"
- [ ] 圆周模式不点圆边就点打孔 → 按钮应该是**灰的**

## 3. 命令 8「配孔检查」——查漏孔 / 偏心 / 配错

### 操作

1. 点「配孔检查」。
2. 点「**开始检查**」。
3. 等几秒（大装配会久一点）。

### 应该看到

状态栏一行摘要，例如：

> 检查了 24 个孔（8 组同轴孔），发现 2 处问题：漏打孔 1，孔偏了 1

下面列表逐条列出来。**点一条，对应的孔会高亮成橙红色。**

### 判定口径（写在这里方便你判断报得对不对）

| 项 | 口径 |
|---|---|
| 算不算连接孔 | 直径 **3–25mm**；更小的不参与检查 |
| 算不算同轴 | 轴线方向差 **< 2°**，横向偏移 **< 0.2mm** |
| 配做是否合法 | 两孔能匹配到**同一个螺纹规格**就算合法；都匹配不上标准表时，直径差 ≤1mm 放过 |
| 漏打孔 | 某零件上的孔，轴线**射线穿过了另一个零件的材料**，但那个零件在这个位置没有孔 |
| 孤孔 | 只有一个零件有孔、且轴线没穿过别的零件。**默认不报**（真实装配里孤孔太多），想看得把"忽略孤孔"的勾去掉 |

### 重点验证

- [ ] 一个**正确的**配做（M10 底孔 + M10 过孔）→ **不报问题**
- [ ] 故意把目标件的孔打小一号（M8 底孔）→ 报「**配错孔**」
- [ ] 故意把孔偏心 1mm → 报「**孔偏了**」
- [ ] 点列表里的一条 → **对应的孔高亮**

## 4. 出问题了怎么反馈

插件会把异常写到日志：

```
%LOCALAPPDATA%\TianGongCadSuite\panel.log
```

（在资源管理器地址栏粘 `%LOCALAPPDATA%\TianGongCadSuite` 就能打开）

反馈时请带上：**你点的什么 → 期望什么 → 实际什么 → panel.log 最后几行**。有截图最好。

## 5. 自动化测试（不用手点，可以随时跑）

如果你只想确认代码没坏，不用点鼠标：

```powershell
cd DEV_0.4_插件框架

# 纯逻辑，秒出结果，不需要 CAD
build\autohole-5\PanelTests.exe --autohole-pure

# 原生端到端：会自动起一个独立 CAD 实例，跑完自己退出
build\autohole-5\PanelTests.exe --autohole         artifacts\t1   # 命令 6：照孔打孔
build\autohole-5\PanelTests.exe --autohole-multi   artifacts\t2   # 命令 6：一次多选不同大小的参考孔
build\autohole-5\PanelTests.exe --autohole-pattern artifacts\t3   # 命令 7+8：排孔 + 配孔检查
build\autohole-5\PanelTests.exe --autohole-form    artifacts\t4   # 三个窗口的显示/重复初始化

# 看命令有没有注册齐（不需要 CAD）
build\autohole-5\PanelTests.exe --commands

# 插件能不能被 CAD 加载（会起一个 CAD 实例）
tools\verify-autohole.ps1
```

### 各条命令应该输出什么

| 命令 | 通过标志 |
|---|---|
| `--autohole-pure` | `AUTO-HOLE PURE ASSERTIONS 65`，没有 `FAIL` |
| `--autohole` | `AUTO-HOLE NATIVE ASSERTIONS 17`，含"B 板切除体积…3654.5 mm³ / 期 3654.5 mm³"和"A 板（参照件）未被改动" |
| `--autohole-multi` | `AUTO-HOLE MULTI ASSERTIONS 19`，含"一次打出 2 个孔"、"两个不同大小的孔体积吻合（实 4763.4 / 期 4763.4 mm³）" |
| `--autohole-form` | `AUTO-HOLE FORM ASSERTIONS 7`，三个窗口重复初始化后仍然可见 |
| `--autohole-pattern` | `AUTO-HOLE PATTERN ASSERTIONS`，含等分 4 孔、圆周 6 孔、腰孔三段的体积吻合 |
| `--commands` | `COMMAND COUNT 8`，能看到命令 6/7/8 |
| `verify-autohole.ps1` | `MENU Registered 8 commands` |

> **注意**：纯逻辑测试在任何模式下都会先跑一遍，所以你会看到 `AUTO-HOLE PURE ASSERTIONS` 出现两次，这是正常的，不是重复执行出错。

> **一个会"卡死"的坑**：这些脚本会启动真实的 CAD 实例。如果 CAD 弹出一个**模态对话框**（最常见的是"此文件已存在，要覆盖它吗？"），脚本会一直等下去，看起来像卡住了。
> 遇到就先点掉那个框，然后：
> ```powershell
> Get-Process -Name TianGong -ErrorAction SilentlyContinue | Stop-Process -Force
> ```
> 再用一个**全新的输出目录**重跑。`--autohole` 和 `--autohole-pattern` 会自动建带时间戳的子目录，不会撞；`command-routing-native-test.ps1` 现在也会先清掉旧夹具。

## 7. 已知限制

- **一个轮廓只能放一个孔**：底层 API 实测"一个轮廓里放 4 个 Holes2d 只会切出第一个"，所以 N 个孔 = N 个特征。功能没问题，特征树会多几条。
- **腰孔是"通切特征"不是"孔特征"**：`Holes2d` 只能做圆孔，腰孔走的是拉伸切除。几何一样，但特征类型不同。
- **必须打开外部参考**：跨零件选面依赖它（和 ICAN 一样的要求）。
- **两零件不平行无法照孔打孔**：这是"照孔投影"这个机制的固有约束，会明确报错而不是静默失败。
