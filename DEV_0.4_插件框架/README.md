# 天工 CAD 插件平台 DEV 0.4

新增“导出出图训练数据”（命令 ID 4）：导出模型网格、三维边面、工程图视图、尺寸与公差、PDF 和原始文件副本；配套脚本生成 SVG、PNG、训练索引和验证报告。格式、使用方法和未完成项见 [TRAINING-EXPORT.md](TRAINING-EXPORT.md)。

主开发入口。宿主负责 AddIn 连接、命令注册和窗口生命周期；新增业务通过 IToolModule、ModuleCatalog.Create 接入。现有四面生成内嵌板、型材自动填充、Lineup 模型标记、导出出图训练数据四个命令。

## 更新安装

运行 Install.cmd 将当前源码编译到独立的 build/release 时间目录并注册。编译失败不会切换注册路径。保存自己的工作后重启天工 CAD 才会加载新 DLL；已打开的 CAD 仍使用内存中的旧版本。

菜单灰色问题已修复：CAD 回调使用本地命令编号，StartCommand 使用宿主分配的运行时编号。Lineup 是装配级清单，请激活已保存的 ASM；可在其中选择普通 PAR 零件、子装配及子装配内部零件。单独打开 PAR 文件的环境尚无独立 Lineup 项目入口。

## 五类清单快捷工作流

1. 打开已保存的装配，点击“插件 → 功能 → Lineup 模型标记”。工具分为新增、编辑、编号与阀岛、型号库、导入导出、视图六个菜单。
2. 在“编号与阀岛”设置项目号、当前阀岛数字及统一阀岛型号。新行按当前类目自动编号，已有编号可手改，不自动重排。普通传感器和其他电气件不需要阀岛设置。
3. 在 CAD 中多选具体零件，使用“新增 → 多选模型加入”；也可先粘贴整张清单，再按行“绑定下一行”。同一零件装在不同位置会分别关联；重复选择已绑定实例会跳过。
4. 双击“型号”或按 F4 搜索型号库，可套用到多行并填入品牌、接口。保留手工输入，完整信息自动收录。随插件提供从用户样表提取的 43 个型号规格；同型号不同品牌/接口分别保留。
5. 选中气缸行，使用“从气缸生成 H/W”，一次创建两个传感器记录，再分别选择型号和绑定模型。
6. 点击“点选模型”切换为 440×160 小窗口，逐个选择 CAD 零件后按“绑定并下一条”；“返回表格”恢复尺寸。表格默认显示常用字段，“视图 → 完整字段”可编辑全部字段。
7. “导入导出 → 复制五类清单到 WPS / Excel”可直接粘贴；也可导出 UTF-8 CSV。五个分类段、11 个业务列与用户样表一致。

编号示例：OK170-Y1C01、OK170-Y1V01、OK170-Y1C01H/W、SE01、E01。已有 C05-1/C05-2 保留，H/W 追加在完整气缸编号后。各阀岛独立递增；同项目同 Y 数字的阀片共用一个阀岛型号，在导出安装方式列的该岛第一条阀片上标注一次，不占用阀片自身型号。

编辑自动保存到装配旁同名 .lineup.xml；型号库保存在 %LOCALAPPDATA%\TianGongCadSuite\lineup-models.xml。未编号预留行允许保存导出；重复编号拒绝。CAD 持久化关联键独立保存，不占用业务“型号”列。损坏/跨装配项目拒绝加载，旧记录无键需重新绑定。装配另存后需重新打开清单。

## 验证及边界

使用 tools/build.ps1 构建；PanelTests.exe 检查核心，--table <目录> 检查样表，--smart <目录> 检查编号和型号库。table-native-test.ps1、smart-native-test.ps1、command-routing-native-test.ps1 分别启动独立 CAD 检查表格工作流、智能录入/零件关联、命令调度。使用不同的独立输出目录。

新版证据见 [智能录入与零件关联报告](LINEUP-SMART-VALIDATION-20260909.md)。历史证据见 [原生关联初期报告](LINEUP-VALIDATION-20260909.md)。原生 API 通过和 WinForms 位图预览不等同于桌面鼠标交互验收。

尚未完成：写回 CAD 自定义属性、模型编号箭头/引线、XLSX 工作簿及图文报告、任意表格字段映射/交互合并冲突。选择无法明确解析为实例时会提示到装配树选具体零件，绝不按同名猜测绑定。

- “绑定并下一条”成功后清空 CAD 旧选择；小窗口独立保存待绑定记录 ID，切换窗口和表格重载不依赖隐藏网格的当前行。

- 原位、安装方式默认显示在编号之后，无需切换完整字段。
- 当前注册路径更新为 build/binding-ui-20260909/TianGongCadSuite.dll，保存工作并重启 CAD 生效。
