# Lineup 快速录入

常用工作流改为“设置本批字段 → 选择模型”。连续模式开启后，每个模型选择稳定约 0.7 秒即录入，无须再次点击绑定或保存。

## 三种录入方式

| 场景 | 操作 | 自动完成 |
| --- | --- | --- |
| 同类零件批量新增 | 填一次共用字段，多选模型，点击“加入 / 新增” | 新编号、实例绑定、父级关系、保存；可同时生成 H/W |
| 连续新增 | 填一次共用字段，点击“连续新增”，随后逐个选模型 | 每次选取自动新增和保存，重复实例不重复录入 |
| 已有表格逐条绑定 | 导入或选择已有行，点击“连续绑定”，随后逐个选模型 | 自动跳到下一条未绑定行，末行完成自动停止 |
| 暂无 CAD 模型 | 填共用字段和数量，按 Enter | 按数量新建已编号记录，之后可连续绑定 |

有 CAD 选择时，以实际选择的不同实例数为准，“数量”仅用于无模型选择时。一个零件文件的多个装配实例分别绑定，不按名称合并。

## 共用字段和层级

- 类目、型号、品牌、接口、描述、机构、原位、安装方式和上级选择按类目记忆，随 `.lineup.xml` 保存。切换类目会保留本窗口尚未提交的共用字段。
- “沿用当前行”只复制共用字段；新记录的编号重新生成，IO 地址留空。需要不同描述时可在表格直接修改，或在新增前改录入区。
- 已选气缸上级阀片时，气缸编号跟随该阀片；一片控制多缸时使用 `C01-1 / C01-2`。原有子记录的编号会依既定层级规则联动，手工 IO、备注和 CAD 绑定保留，整批可撤销。
- 阀片新增时自动关联当前前缀和 Y 数字对应的阀岛。各岛型号仍在“编号与阀岛 → 管理阀岛”维护。
- 同时生成的 H/W 拥有独立记录 ID、气缸 / 阀片 / 阀岛关系。已有气缸传感器共用规格时沿用其型号 / 品牌 / 接口 / 安装方式，否则这些规格留空；不复制气缸型号。
- 气缸传感器单独新增需选择气缸及 H/W/M 位置；已存在的位置用“连续绑定”，重复位置不会另建。
- 型号库规格唯一时补全空的品牌和接口；同型号有多种规格时用录入区 F4 选择。CAD 文件名不会被猜测为业务型号。

## 连续模式与撤销

- 明确点击“连续新增”或“连续绑定”才开始监听，打开项目不会自动启动。
- 连续绑定按照当前筛选和排序后的可见行顺序执行，从当前未绑定行开始，只向后前进，跳过已绑定行。
- 每次只选择一个待绑定模型。选择重复模型、多选或无效对象时保留当前待绑定行；修改选择后继续。
- 连续模式下手动绑定 / 另建按钮禁用，避免两条录入路径交叉；停止后恢复。
- “停止连续”、Esc、“返回表格”、关闭窗口均停止监听；撤销也先停止监听，然后撤销上一整批新增或绑定。
- 模型关联保存成功后清空 CAD 选择；切换到其他装配不录入，回到所属装配后可继续。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| Enter（录入区）/ Ctrl+Enter | 加入所选模型，或按数量新增 |
| F4 | 录入区选择本批规格；表格选择当前行规格 |
| Ctrl+V（表格） | 粘贴矩形区域 |
| Ctrl+D（表格） | 向下填充共用字段，编号和地址受保护 |
| Ctrl+Z（表格）/ 撤销按钮 | 撤销上一操作 |
| Esc（连续模式） | 停止自动录入 |
