# 多型材自动填充 — DEV 0.2.0

新增“多型材自动填充”入口，保留原来的手动选四面和定位点入口。自动模式复用原有 PanelGeometry.Solve 和 CadBuilder，新增的是型材实例读取、闭合框口识别与批量输出。

这是独立开发验收版。原生天工 CAD 建模接口实测已通过；完整鼠标点选、文件对话框操作链和用户实际框架的现场验收尚未完成。以 VALIDATION-0.2.md 为准。

## 安装与操作

1. 将整个文件夹放在固定位置，双击 Install.cmd。开发版使用独立 CLSID、命名空间和 TianGongPanelAuto.dll，可与原 DEV 0.1.2 共存。
2. 保存自己的工作后重启天工 CAD。在“自动填充 DEV”工具组中点击“多型材自动填充”。已加载插件时也可双击 build/PanelLauncher.exe 打开自动模式。
3. 使用 CAD 的零件选择工具，Ctrl 多选或框选同一平面上的型材实例；也可选择一个包含这些型材的框架子装配。不要选面、边或草图。可先选再开插件，也可在窗口打开后选择，再点“读取当前选择并识别框口”。
4. 输入总厚度和每边间隙（mm）。默认 6 mm 厚、0 mm 间隙；厚度中心自动取各型材截面厚度中心的共同平面，不再要求逐个选面或选边中点。
5. 左侧列出全部识别到的框口，点击列表逐个检查蓝色板子预览。中间立柱/横梁分隔出的框口会分别生成，不会生成覆盖横梁的大板。
6. 点击“批量保存并插入全部框口”，选择输出目录。程序新建独立批次子目录，每个框口生成一个可编辑 PAR，附尺寸清单 CSV。全部板子插入当前装配后，请自行保存装配。

更改厚度和间隙只重新计算已读取的几何，避免反复读取大量 CAD 面；调整框架后应点击重新读取。实际生成前会再次读取源几何。

## 当前支持范围

- 同一共同中面、两组相互垂直的直型材组成的闭合矩形框口；支持一个或多个框口。
- 普通 PAR 装配型材、天工 StructuralFrames 原生定长/斜接实体、旋转和平移后的嵌套框架子装配。
- 同一个 PAR 的不同实例独立处理；重复选中同一实例会去重。
- 自动定位采用型材厚度中心；厚度超出共同深度、型材中心不共面、缺边、断角、不连续内侧面及非矩形框口会拒绝。
- 单次最多 200 根型材；大框架请分组选取。

自动边界取型材外轮廓之间的净框口，正间隙向净框口内缩。**本版不会自动把玻璃板伸入铝型材槽底，也不推断槽口装配意图。** 如果板厚处存在槽口、缺口、圆角导致内侧面不连续，自动模式会要求改选或使用手动选四面。不同平面的立体框架需要按面分组。短块、曲型材、斜边框口、多实体零件等不在本版自动范围内。

本版不关联更新已有板子、不自动去除之前生成的板子、不修改源型材，不检查未选中零件的干涉。重复点击生成会创建新的一批板子。

## 输出与失败处理

不覆盖已有文件。每个批次单独建目录；任何一个板子失败，会尝试撤回本批此前插入的板子并删除对应新 PAR。如果撤回失败，会明确列出残留路径。不会以已完成的提示掩盖部分失败。

开发日志：%LOCALAPPDATA%/TianGongPanelAuto/panel.log。

Uninstall.cmd 只卸载 DEV 0.2.0 的当前用户注册；不卸载原版，不删除生成的模型。

## 复现测试

在独立天工 CAD 实例中创建全新样件，不要在有未保存工作的生产实例中运行测试。

```powershell
powershell.exe -NoProfile -File tools\build.ps1
build\PanelTests.exe
powershell.exe -NoProfile -File tools\install.ps1
powershell.exe -NoProfile -File tools\native-test.ps1 -OutputPath artifacts -NewInstance
```

只重跑自动填充的原生测试，可加 -AutoOnly。需要本机天工 CAD 2025 和其自带方管库 20x1.5.par，其他安装位置请按原工具的 CadHome/TIANGONG_HOME 选项配置。

examples 中提供测试模型与预览图。样件使用 CAD 的原生框架特征生成，并有真实 PAR 实体及保存重开检查；不是仅绘制了一个示意框。模型引用保存于本机测试工作目录，移动到其他机器后的引用重定位尚未验证。

## 开发实现

- src/AutoFrame.cs：实例去重、嵌套遍历、原生框架覆盖实体坐标变换；按型材长轴建立局部平面，用占用网格和外部连通区域排除开口，再验证矩形四边在整段板厚内有连续的实际平面支撑。
- src/AutoPanelForm.cs：批量选择读取、厚度/间隙、逐框口预览及整批输出/回退。
- src/Geometry.cs、src/CadInterop.cs：继续使用原四面求解和可编辑草图/对称拉伸建模过程。
- tests/AutoTests.cs：实际 StructuralFrames、单/双框口、嵌套变换、重复选择、保存重开与失败回退测试。

接口参考：[Siemens HasBodyOverride 文档](https://support.industrysoftware.automation.siemens.com/trainings/se/107/api/SolidEdgeAssembly~Occurrence~HasBodyOverride.html)。覆盖实体已经位于其所属装配坐标中，不能再次直接套零件实例矩阵。本实现通过覆盖实体反变换与目标实例变换组合处理，并在天工本机上验证。
