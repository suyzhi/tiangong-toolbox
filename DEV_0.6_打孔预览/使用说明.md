# 天工工具箱 DEV 0.6.0 · 使用说明

天工CAD 插件。本版重点是**自动打孔**（命令 6）的参数面板：现在能直接看到孔打出来是什么形状。

---

## 一、安装

1. 保存好当前工作，关掉天工CAD。
2. 双击 **安装.cmd**（按当前用户注册，不需要管理员）。
3. 启动天工CAD → 工具 → 插件管理器里启用 **天工工具箱 (DEV 0.6.0)** → 重启 CAD。
4. 功能区出现「天工工具箱 DEV 功能」选项卡。

卸载：双击 **卸载.cmd**，然后重启 CAD。

> 本版从 DEV 0.5.1 升级：先跑一次 **卸载.cmd** 再跑 **安装.cmd**，避免两份注册打架。

---

## 二、本版新增：孔的孔形状参考面板

运行命令 6「自动打孔」后，窗口下半部分多了一张 **孔形状参考** 卡片：

| 位置 | 内容 |
|---|---|
| 左 | **剖面图**：按实际孔型画的 2D 剖面，带尺寸标注 —— 孔口 Φ、主孔 Φ、沉孔 Φ 与深、锥孔 Φ 与锥角、孔口倒角、V 型底角度、盲孔深度、参考板厚 |
| 右 | **3D 参考**：打孔后的数模长什么样的半剖轴测图（切开的前半块用虚线虚影画出来，所以看得出是剖视） |

- **改任何一个参数，两张图立刻跟着变。**
- **没点参考孔也能看**：还没在模型上点孔时，参数面板编辑的是"草稿规格"，
  可以先把孔型调出来、看清楚形状，再去模型上点孔。
- 螺纹孔按螺纹内小径画实体孔，公称直径用细虚线画在外面 —— 和 CAD 里的"装饰螺纹"一致。

### 参数面板的排版也重做了

- 左边选东西（① 点孔 ② 点面），右边定规格（③ 定规格），孔形状参考和下边的按钮通栏。
- 参数改成固定栅格：标签和输入框都对齐，`mm` / `°` 紧跟数字。
- "这个规格是怎么来的 / 正在改谁"搬到独立的「规格来源」卡片，不再挤在输入框旁边。

## 三、命令 6「自动打孔」怎么用

1. **点孔**：在模型上点孔口的**圆形边线**。可以连点好几个，大小可以不一样。
   每个直径归一组，孔型和规格自动反推。
2. **点面**：点要打孔的那个**平面**，可以连点好几个。
3. **定规格**：默认是自动反推的，不动就按它打；要改就在右边的参数里改，
   改完在「孔形状参考」里确认形状对不对。
4. **看预览**：窗口下方的「预览」会写清楚打几个孔、什么孔、分布在哪些面上。
5. 点 **开始打孔**（或 Ctrl+Enter）。完了记得保存装配。

自动反推的规则（和 ICAN 的配做逻辑一致）：

- 参考孔是**螺纹底孔** → 目标件配做**沉孔**（目标件要过螺钉头）
- 参考孔是**过孔** → 目标件配做**螺纹孔**（目标件要攻丝）
- 认不出标准规格 → 按同直径通孔处理，并在状态栏说明
- 直径落在两个规格的容差边缘 → 明确提示"请手动确认规格"，不闷声替你选

## 五、已知限制

1. 图里的**板厚是示意值**：面板拿不到目标零件的真实厚度。贯通孔的板厚不影响孔的形状；
   盲孔保证孔底还有余料。图上都写明了"板厚 x.x 为示意"。
2. **锥形沉孔不叠加孔口倒角**：CAD 侧本来就跳过（锥座本身就是倒角），预览保持一致。
3. **孔口倒角角度限制 10～89°**：实测 90° 时轴向深度为 0，没有意义。
4. **3D 参考是通用示意**，不是当前装配的渲染图：它画的是"这样的孔打在这样一块料上是什么样"。

## 六、本版修掉的 4 个问题

1. 勾了"盲孔"，深度框还是灰的（填不了深度）。
2. 没点参考孔时，在"规格"里选 M6 不回填孔径（还停在 6.00）。
3. 换孔型/换规格会把已经手改的贯通/盲孔/倒角冲掉。
4. 参数卡片在"通孔"时中间留一条空带（沉孔那一行的位置空着）。
