# 自动打孔 · 孔形状参考面板（DEV 0.6.0）

这一版解决的是使用者的原话：

> 这个参数面板可以生成孔的形状吗？方便工程师参考打出来的孔会是什么样子。
> 然后我觉得还可以添加一个打孔后的数模会长什么样的 3D 参考预览页面。
> 然后我看一些控件都不是对齐的，字体排列也很奇怪。

对应四件事：**① 剖面预览 ② 3D 参考 ③ 排版重做 ④ 顺手修掉的四个真 bug**。

---

## 1. 孔形状参考面板

一张通栏卡片，左边 2D 剖面，右边 3D 半剖轴测，改任何一个参数两边立刻重画。

### 1.1 左：剖面（孔的尺寸）

- 材料按剖面线画，孔是空腔（背景色），中心线点划线。
- 尺寸标注按孔型自动决定：孔口 Φ、主孔 Φ、沉孔 Φ 与深、锥孔 Φ 与锥角、
  孔口倒角 `0.5×45°`、V 型底 118°、盲孔深度、参考板厚。
  能塞进孔腔里的尺寸就画在孔腔里（那里是空的，不挡东西）。
- 螺纹孔：实体孔按螺纹内小径画，公称直径用细虚线画在外面 —— 和 CAD 里"装饰螺纹"的
  表达一致，也和实际切出来的形状一致。

### 1.2 右：3D 参考（打孔后的样子）

- 轴测图 + **半剖**：切掉靠观察者的前半块，露出孔的轴向剖面。
  不剖的话从外面只看得到一个椭圆，分不出通孔 / 盲孔 / 沉孔。
- 被切掉那半块用**虚线虚影**画出来，看图的才知道"这是剖开看里面的"，而不是这块料本来就这样。
- 孔口画成能看进去的开口：沉孔看得见侧壁和孔底、锥沉看得见锥座、螺纹孔多一圈装饰螺纹虚线。
- 容易看错的那个特征带一根引线标注（沉孔 Φ/深、锥孔 Φ/角度、孔口倒角、装饰螺纹规格）。

### 1.3 两份视图吃同一份几何定义

`src/HoleProfile.cs` 里的 `HoleShape` / `HoleShapeBuilder` 是**唯一**的一份孔形状定义：
纯计算、不碰 CAD、不碰界面。2D 剖面、3D 参考、以及 CAD 里实际切出来的形状，必须对得上。
所以它可以直接被 `tests/AutoHoleTests.cs` 断言（见 `ShapePure()`，87 条）。

## 2. 孔口倒角的真实几何（真机实测）

预览要画"孔口倒角 0.5×45°"，但 Solid Edge 的

```
HoleData.SetStartChamfer(Index, Setback, Angle)
```

里 `Setback` 到底是轴向深度还是径向宽度、`Angle` 从轴线量还是从端面量，文档没说清。
45° 时四种解释结果完全一样 —— 所以**任何非 45° 角度都可能画错**。

做法：`tools/ChamferProbe.cs` 在 10mm 厚板上打一串 Φ6 通孔，逐个量切除体积，
减掉纯圆柱体积得到倒角环体积，再和四种候选解释对表。

| Setback | Angle | 实测倒角环 | A 轴深S/径S·tanA | B 轴深S/径S/tanA | C 径S/轴深S·tanA | D 径S/轴深S/tanA |
|---|---|---|---|---|---|---|
| 0.5 | 45° | 2.487 | 2.487 | 2.487 | 2.487 | 2.487 |
| 2   | 45° | 46.077 | 46.077 | 46.077 | 46.077 | 46.077 |
| 2   | 60° | **26.602** | 90.430 | 24.558 | 79.807 | **26.602** |
| 2   | 30° | **79.807** | 24.558 | 90.430 | 26.602 | **79.807** |
| 3   | 60° | **65.297** | 231.741 | 58.397 | 195.890 | **65.297** |

（单位 mm³，Φ6 通孔在 10mm 板上，圆柱体积 282.743 mm³）

**结论（D 列三个非 45° 用例全部精确吻合）：**

```
Setback = 孔口的径向增量（不是轴向深度）
Angle   = 与孔轴的夹角（不是与端面的夹角）
轴向深度 = Setback / tan(Angle)
```

反直觉的一点：**角度越大，倒角越浅**（60° 只有 45° 的约 58% 深）。
这条已经写进 `HoleShapeBuilder.ChamferDepthMm` 的注释和 `ShapePure()` 的断言里。

> 90° 那一组没测出来：`AddEx` 报了一次瞬态 COM 错（CO_E_OBJNOTREG），而且 90° 的轴向深度
> 按本式就是 0（退化成平面），界面把角度限制在 10～89°，没有实际影响。

复现：`tools\run-chamfer-probe.ps1`（在私有桌面上跑，不打扰用户桌面），
日志落在 `artifacts/chamfer-probe/chamfer-probe.log.txt`。

## 3. 排版重做

原来是**一列到底**：十个区块从上往下堆，参数挤在一张 226px 高的卡片里，
"正在编辑…"和螺纹说明塞在倒角那一行的右边，字号还比输入框小一号。

现在：

```
┌─ 左列（选东西）─────────┬─ 右列（定规格）──────────────────┐
│ ① 点孔 + 参考孔列表      │ ③ 定规格 + 孔参数（栅格）        │
│ ② 点面 + 打孔面列表      │ 规格来源（三行说明）             │
├─────────────────────────┴──────────────────────────────────┤
│ 孔形状参考：剖面（左） | 3D 参考（右）                       │
│ 预览                                                          │
│ [开始打孔] [全部重选] [关闭 (Esc)]      状态栏               │
└──────────────────────────────────────────────────────────────┘
```

具体做法：

| 问题 | 做法 |
|---|---|
| 控件不对齐 | 参数行改成**固定列的栅格**：标签 0/140/272，控件 34/174/306。同类控件等宽，位置是算出来的，不是一个个手摆的 |
| 单位跑到老远 | `mm` / `°` 紧跟数字，8.25pt 灰字 |
| 中英混排、字号跳 | 标签 9pt 正文色；单位 8.25pt 灰；说明 8.25pt 灰；卡片标题 9pt 粗体 + 8.25pt 灰说明；步骤条 9pt 粗体 + 9pt 灰 |
| 参数卡片中间一条空带 | 沉孔/锥沉那一行不显示时，倒角行顶上去，卡片高度从 164 收到 134 |
| 说明文字挤在输入框旁边 | "正在编辑谁 / 这个规格怎么来的 / 螺纹与孔底的通用提示"搬进独立的「规格来源」卡片 |
| 列表右边一大块空白 | 按钮贴底，按钮列上方放"共 N 组 M 个"计数 |
| 说明文字被卡片边缘硬切 | 宽度按父容器现算（用 Anchor 会被"设计时尺寸→实际尺寸"的差值撑到几千像素宽） |
| 步骤说明串到隔壁列 | 用带省略号的矩形画，列宽不够就截断 |
| 窗口最小尺寸下参数被切 | 左列改成按比例（0.365），参数栅格按 430px 内宽设计 |

窗口从 680×800 改成 900×880（最小 780×800），因为两个预览视图需要真正的宽度。

## 4. 顺手修掉的四个真 bug

### 4.1 勾了"盲孔"，深度框还是灰的（填不了深度）

`WriteBack()` 在"没选中参考孔"这条路上直接 `return`，跳过了 `ShowKindFields()` ——
而"哪些框能用"正是它负责的。用户勾上盲孔，深度框仍然是灰的。

修法：草稿分支也要走 `ShowKindFields()`。
回归断言：`--autohole-ui` 的"改成盲孔后深度框必须可用（曾经是灰的）"。

### 4.2 没点参考孔时，选标准规格不回填尺寸

`ApplySizeChange()` 开头就是 `if (g == null || si <= 0) { WriteBack(); return; }` ——
没选中参考孔时，"规格"下拉框选 M6 什么也不会发生，孔径还停在 6.00。

修法：孔型和规格一律按标准表重填，有选中的参考孔就写那一组，没有就写草稿，两条路走同一段代码。

### 4.3 换孔型/换规格会把用户手改的项冲掉

原来 `ApplyKindChange` / `ApplySizeChange` 只保留 `Depth/Bottom/Chamfer…` 这几项，
新增的项漏一个就会被标准表覆盖。现在统一走 `CopyUserEdits()`，要保留什么一目了然。

### 4.4 拿 `Control.Visible` 当布局依据

`ShowKindFields()` 原来用 `cboreRow.Visible || csinkRow.Visible` 判断"沉孔那一行在不在"，
但 `Control.Visible` 的 getter 在**父窗口还没显示**时一律返回 false ——
这个判断在真机上碰巧是对的，在无窗口环境下就是错的（加界面回归测试时当场翻车）。
改成按孔型算：`k == Counterbore || k == Countersink`。

## 6. 已知限制（写清楚，免得被当成 bug）

1. **板厚是示意值**：面板里拿不到目标零件的真实厚度（那要额外走一遍 COM 去量）。
   剖面和 3D 里的板厚都按规格估一个，并在图上写明"板厚 x.x 为示意"。
   贯通孔的板厚不影响孔的形状；盲孔只保证孔底还有余料。
2. **锥形沉孔不叠加孔口倒角**：CAD 侧 `BuildHoleData` 里明确跳过了（锥座本身就是倒角），
   预览也同步跳过，避免画出一个实际不存在的倒角。
3. **倒角角度限制在 10～89°**：90° 时轴向深度按实测公式是 0，没有意义。
4. **3D 是多孔参考，不是真实装配**：它画的是"这样的孔打在这样一块料上是什么样"，
   不是当前装配的渲染图。要看真实渲染请用 CAD 自己的视图。
5. **不成立的规格会被拒画**：例如沉孔直径 ≤ 孔径。这时两个视图显示原因而不是形状
   （`HoleShape.Problem`）。CAD 侧同样会拒绝这种参数，所以不存在"预览画得出、实际打不出"的情况。
