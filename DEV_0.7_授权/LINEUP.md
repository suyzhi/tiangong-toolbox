# Lineup 排位清单 · 使用教程（方案 A 气动主线版）

> **一句话定位**：在天工 CAD 装配里直接按 **「阀岛 → 阀片 → 气缸 → H/W 磁开」** 搭建气动系统，分表整理 **普通传感器 (SE)** 与 **其他电气件 (E)**，并完成 **自动截图画红箭头 → 签字页自检 → 一键导出公司标准 5 页签 `.xlsx`**。所有数据自动保存在装配旁的 `.lineup.xml`，绝不改动三维模型。

---

## 30 秒看懂三步流程

打开已保存的总装配或工位装配（`.asm`），点击功能区 **「天工工具箱 → Lineup 模型标记」**：

1. **① 整理清单**：
   - **气动系统（默认视图）**：左侧管理 **阀岛 / 汇流排 / 阀组 / 单片阀**，右侧按阀路对照直接管理 **阀片、气缸与 H/W 磁开**；
   - **普通传感器 (SE)** 与 **其他电气件 (E)**：各自独立精简分表，无冗余空列；
   - **BOM 总表**：保留全部 5 类 Excel 式总览，支持批量复制粘贴与 `Ctrl+D` 向下填充。
2. **② 标位置图（可选）**：截取当前 CAD 视角或正交等轴测，**自动识别已绑 3D 模型并画原生红色箭头**，也支持左键点图手调与多页分机构出图。
3. **③ 检查导出**：自动对照公司《签字页》8 项审查条款查漏补缺，确认抬头后右下角一键直出 5 页签 `.xlsx`。

---

## 第一步：整理清单

### 1.1 首次打开空装配：4 种入口任选

| 入口 | 适用场景 | 怎么用 |
| :--- | :--- | :--- |
| **① 先建阀岛 (Y1)（推荐）** | 正向搭建气动框架 | 点击 **`+ 新建阀岛 (Y1)`**，设好工位前缀（如 `OK170`）、形态（`阀岛 / 汇流排 / 阀组 / 单片阀`）和型号（如 `SS5Y5-20-08`），可选预铺 N 片空阀位。 |
| **② 自动扫描装配** | 标准件命名规范的装配 | 一键扫出顶层及子装配中的气缸、阀岛与传感器，勾选确定自动入表并绑定三维零件。 |
| **③ 在 CAD 点选加入** | 文件名不规范的装配 | 窗口收成 `440×180` 悬浮条，三维里点哪个零件就录入并绑定哪个。 |
| **④ 导入已有清单** | 复用历史项目 / 同事表 | 导入 `.xlsx / .xlsm / .xls`（**支持公司透明加密表格**，自动通过本机 Excel / WPS 只读读取）或从剪贴板粘贴，自动反推阀岛与层级关系。 |

---

### 1.2 气动主线（阀岛 → 阀片 → 气缸 → H/W 磁开）

1. **左侧阀岛 / 阀组栏**：
   - 点顶部 **`+ 新建阀岛`** 随时新增 `Y1 / Y2 / Y3…`（自动顺延序号），支持 4 种形态：`阀岛`、`汇流排`、`阀组`、`单片阀`。
   - 每张阀岛卡片实时显示型号、`阀片 / 气缸 / 磁开` 数量及 `3D✓` 绑定状态；双击卡片或点底部 **`编辑阀岛`** 改型号，点 **`绑 3D`** 把 CAD 当前选中件绑为阀岛本体（已绑后变为 **`定位 3D`**），点 **`删除`** 可安全删除（含单步撤销）。
   - 若扫描或导入了未带 `-Y*` 编号的孤立气缸，底部会出现橙色 **`未归属气动件 (N)`** 分组，点开即可 **`一键归属到阀岛…`**。
2. **右侧操作与 4 个子视图**：
   - **`+ 添加气缸`（主按钮）**：在当前选中阀岛自动避让已有槽位，一次性生成配套 **`V**` 阀片 + `C**` 气缸 + `H/W` 磁开**，并沿用本岛常用阀片与磁开规格，光标直接落入气缸描述格供打字。
   - **`+ 添加阀片 ▾`**：单加或批量铺设 N 片标准阀片、**预留位 / 盖板**（自检自动跳过缺气缸提醒）、或 **吹气 / 破真空阀路（无磁开）**。
   - **`CAD 识件 ▾`**：直接把 CAD 当前选中件加为本阀岛气缸（自动配阀+H/W）、连续点选加入、扫描整机或连续绑定本岛未绑气缸。
   - **4 个子页自由切换**：
     - **`按阀路对照`（默认）**：一行看清 `阀片号 → 阀片类型/型号 → 所控气缸 → 气缸描述/型号/品牌/原位/安装方式 → 磁开 H/W → 3D 绑定`。**一阀控多缸** 自动以淡蓝续行 `↳ 同 Y1V02` 展示；改气缸描述自动同步阀片功能参数和磁开描述。
     - **`气缸明细`** / **`阀片明细`** / **`气缸传感器`**：各自只展示本类专属列。在 **`气缸传感器`** 子页点右上角 **`统一套用磁开型号`**，可 2 秒把 `D-M9B / SMC / 2 m 导线引出型` 填满整座阀岛；在 **`阀片明细`** 子页点 **`批量选阀片型号`** 同理。
   - **右键任意阀路行** 可直达：
     - **`+ 给此阀片挂载气缸`** / **`+ 追加同阀气缸（一阀控多缸 C**-1 / C**-2）`**
     - **`磁开 (H/W) 配置 ▸`**（标准 `H/W` · 双组 `H1/W1/H2/W2` · 清除磁开）
     - **`标记为预留位 / 盖板`** · **`将此阀路移动到其他阀岛…`**（整路含多缸与磁开联动重编）
     - **`在 CAD 中定位模型`** · **`绑定 CAD 当前选中件到此行`** · **`删除整路 / 仅删气缸保留空阀片`**

---

### 1.3 普通传感器 (SE) · 其他电气件 (E) · BOM 总表

- **`普通传感器 (SE)`**：只展示 `编号 / 描述 / 型号 / 品牌 / 常开/常闭 / 传感器接口类型 / 备注 / 3D 绑定`。点 **`+ 添加传感器 (SE)`** 自动编 `SE01` 并直接进入描述输入；注意**只有常闭传感器**需在「常开/常闭」列填写。
- **`其他电气件 (E)`**：只展示 `编号 / 描述 / 型号 / 品牌 / 备注 / 3D 绑定`（三联件、伺服、相机、安全门锁、按钮盒等）。点 **`从阀岛同步本体到 E**`** 可幂等同步已建阀岛本体进入 `E**` 清单。
- **`BOM 总表`**：保留全部 5 大类 Excel 风格表格，支持与 WPS/Excel 整块复制粘贴、`Ctrl+D` 向下填充、展开 `批量录入 ▾` 及 `更多 ▾ → 显示全部字段`。

### 1.4 流畅表格手感

- **单击直接输入**：单击任意可编辑格立刻出光标打字，0.5 秒防抖自动保存。
- **双击型号选库（或按 `F4`）**：自动带出品牌和传感器接口类型；新录入的完整型号保存后自动沉淀进本机型号库。
- **自由缩放与浏览**：`Ctrl + 滚轮` 或左下角 **`− 100% +`**（70%～160%）在气动表、电气分表与 BOM 总表间实时同步缩放；`Shift + 滚轮` 左右横移；右上角 **`显示 3D 预览`** 在全部 4 个视图下均可边改表边转三维模型。

## 第二步：标位置图（自动截图 + 自动画红箭头）

点击顶部 **`② 标位置图`**（无需位置图时可直接跳第 ③ 步）：

1. 在天工 CAD 中摆好最清晰的工位或子机构角度，回插件点 **`截取当前 CAD 画面`**（或 **`正交等轴测截图`** / **`导入本地图片`**）。
2. 在弹窗中填页名（如 `总图`、`压紧机构`），勾选本页器件。默认勾选 **「自动识别已绑三维件的箭头位置」**：插件自动隐藏窗口抓取基准图，并通过双色高亮差分（被遮挡时走显隐差分兜底）自动算出每个已绑 3D 件的精确落点，左右无交叉排布。
3. 未绑 3D 或被遮挡的项在右侧标橙点：选中它并在中央图上**左键点一下**，红箭头立刻落位并自动跳到下一条待定位项。
4. 右侧底部用 `左栏 | 自动 | 右栏` 调整方向，点 **备忘** 填接线箱号（如 `1JB`），有气缸缺磁开可点 `+ 补带 H/W`；点右上角 **`+ 新建图页 ▾`** 可按机构建多页。

---

## 第三步：检查并导出标准 5 页签 `.xlsx`

点击顶部 **`③ 检查导出`**：

1. **自动核查**：对照公司《签字页》检查重复编号、必填缺项、气缸↔阀片对应、H/W 齐全、预留盖板/吹气例外、CAD 位置图覆盖率。**双击任意条目直接跳回对应阀岛或分表的精确行**。
2. **确认抬头**：核对项目编号、工位号、线体号、版本号、机械设计与编辑人（自动保存）。
3. **一键导出**：点击右下角 **`导出标准 Excel (.xlsx)`**，直接输出含以下 5 个标准工作表的 `.xlsx`：
   - `LineUP更新日志`
   - `LineUP第一版_配置表`（含阀岛/汇流排汇总与按型号统计）
   - `LineUP第二版_BOM`（5 大类分区、不同 Y 阀岛空行分隔、同阀岛/汇流排安装方式列自动纵向合并、冻结表头、10 列/11 列可选）
   - `LineUP第三版_CAD`（多页 14 列标准版式、高清底图、VLOOKUP 联动 BOM、Excel 原生红色箭头）
   - `签字页`（自动填入本次规范核查结果）

## 常用快捷键速查

| 快捷键 / 手势 | 作用 |
| :--- | :--- |
| **单击格子** | 直接进入输入状态（无需双击），自动保存 |
| **双击型号列 / `F4`** | 打开型号库选型，自动填充品牌与接口 |
| `Ctrl + 滚轮` / 底栏 `− 100% +` | 同步缩放气动表与总表（70%～160%） |
| `Shift + 滚轮` | 表格左右横移 |
| `Ctrl + D` | 同列多行一键向下填充（跳过编号与地址） |
| `Delete` | 清空选中业务单元格（不误删整行） |
| `Ctrl + Z` | 单步撤销（含新建/删阀岛、加气缸、一阀控多缸、换岛、批量套型号） |
| `Ctrl + F` | 定位搜索框即时过滤当前视图 |
| `Ctrl + Shift + P` | 切换 `440×180` 紧凑 CAD 点选悬浮条 |
