# 一键出图（0.11.0，命令 13）

打开零件 / 钣金件 / 装配 → 功能区「一键出图」→「出图」。工程图存在模型旁边（同名 `.dft`；已有人画的图时默认另存为 `名字(自动).dft`，不覆盖）。

## 出的图长什么样（规矩从哪来）

2026-11-03 普查了本机 734 张公司工程图（600 张加密、134 张已解密；`tools/drawing-probe/DftSurvey.cs`，先读了 204 张）+ YF25.07 加工件清单里 40 张带 JPG/PDF 的图：

| 普查结果 | 一键出图的做法 |
| --- | --- |
| 模板：SK先惠 A4 横（约 40%）/ A3 横（约 60%） | 先排 A4，A4 比例不小于 1:1（或和 A3 一样大）就用 A4，否则 A3 |
| 一张图 3～5 个视图：主视图 + 1～2 个投影 + 轴测图 | 主视图看孔最多 / 面最大的那面，长边水平；投影按孔的朝向选（GB 第一角：俯视图在下、左视图在右）；轴测图放右下 |
| 尺寸以坐标尺寸为主（1179 个，线性 500） | 每个视图一串水平、一串竖直坐标尺寸；对称件（中间有孔）以中心为 0（110-0-110） |
| 孔：`4×Ø5.5 贯通`、`2×M4↧8`、沉孔 `⌴Ø11↧6.8` | 同规格孔只标一个；贯通 / 盲孔深度 / 沉孔从三维几何读，螺纹规格和螺纹深度从孔特征读 |
| 圆角 `4-R10`，倒角 `C3`、`4-C2`，模板写「未注倒角 C1（A3）/ C0.5（A4）」 | 同半径圆角一组；等于模板默认值的倒角不标 |
| 刻字引线挂在轴测图上 | 模板自带的刻字引线换成挂在轴测图上的一条 |
| 标题栏：名称、图号、材料、处理、数量、重量、比例、设计、日期 | 模板从零件属性自动带出；比例 = 图纸比例（插件设成主视图比例） |
| 装配图：外形尺寸 + 轴测图序号 + 明细表 | 前视 + 俯视标外形尺寸，轴测图自动序号，明细表用公司配置 SK-BOM |

## 公差和粗糙度（0.11.1）

2026-11-03 普查全部 734 张公司图纸（副本在 `artifacts/dft-corpus/`，`DftSurvey.cs` 的 `tol` 字段，结果 `artifacts/tol-survey/`；642 张零件图页），再用 `ModelHoleSurvey.cs` 把其中 461 张图对应的零件（副本 `artifacts/model-corpus/`）的孔全读出来对照。统计脚本 `artifacts/drawing-bench/tolstats.py / tolstats3.py / tolmodel.py`。

**公司模板本身**：图框右上「其余 Ra6.3」、未注公差表；图框外有一张配合选用表（"H7/k6 … 3. 定位销与销孔"）和两个样例框「⌖ Ø0.03」「◎ A 0.05」——人画图时多是照这个抄。

| 普查结果 | 一键出图的做法 |
| --- | --- |
| 带公差的孔几乎都是定位销孔。只算光孔（三维对照：没螺纹、没沉孔），带公差的比例：Ø4 59%（16/27）、Ø5 55%（21/38）、Ø6 71%（52/73）、Ø8 68%（13/19）；Ø10 45%、Ø3 22%；过孔 Ø4.5 / 5.5 / 6.6 / 9 / 11 几乎是 0 | 光孔 Ø4 / 5 / 6 / 8 → 孔标注加 **H7**（公差带写法里 H7 或它的数值 +0.012/0 占绝大多数） |
| 带公差的小孔 76%（117/152）在孔标注正下方紧贴一个位置度框，写法 `⌖0.03`（73）/ `⌖Ø0.03`（43） | 每个加了 H7 的孔标注下面放一个 **⌖ Ø0.03**（和模板样例一样，带 Ø） |
| Ø20 / Ø30 也常带公差，但 H7 / H8 / G5 / 数值都有，样本集中在两三张图 | 不自动加，留给人 |
| 基准：只有 27% 带公差孔的图页画了基准；平行度 / 垂直度 / 同轴度都要基准 | 不自动加基准，也不加要基准的形位公差 |
| 粗糙度：80% 的零件图页一个粗糙度符号都不画，靠模板「其余 Ra6.3」；画了的 Ra3.2 : Ra1.6 ≈ 2 : 1。有定位销孔公差的图页 34%（30/88）画了粗糙度，其中 27 张是 Ra3.2，多画在销孔 / 螺钉孔所在的安装面上 | 加了 H7 销孔时，给销孔开口的那个面标一个 **Ra3.2**（每个面一个）。**这条依据偏弱**（人画的只有三分之一这么做），在「需要人工确认」里写明 |
| 线性尺寸的公差（槽宽 +0.08/+0.03、±0.05 等）各图各样，找不到和几何对应的规律 | 不加 |

加了什么都写进「需要人工确认」第一条：「公差 加了 N 个定位销孔的 H7 + 位置度 Ø0.03、销孔所在面 Ra3.2（按公司图纸统计的习惯加的，请确认配合 / 基准）」。

## 实现

| 文件 | 内容 |
| --- | --- |
| `DrawingPlan.cs`（纯） | 视图里的图元 → 坐标尺寸落点、基准、文字排开、孔 / 圆角 / 倒角分组、比例、三维孔合并、孔标注文字 |
| `DrawingLayout.cs`（纯） | 选视图、A4/A3、比例、视图位置（公司模板的空白区实测） |
| `DrawingModelRead.cs` | 读零件实体：孔轴向统计、台阶、倒角面、孔（贯通 / 盲孔 / 沉孔 / 孔特征规格） |
| `DrawingViewRead.cs` | 视图里的线 / 圆 / 弧（只要模型边和轮廓边） |
| `DrawingDims.cs` | 往天工里写坐标尺寸、孔标注、半径、引线文字 |
| `DrawingMaker.cs` | 零件图、装配图的整个流程 |
| `DrawingBatchData.cs`（纯）/ `DrawingForm.cs` / `DrawingModule.cs` | 装配里哪些零件要出图（公司编号的加工件；外购件 / 标准件默认不勾）、窗口、命令 |

### 天工接口的实测事实（`tools/drawing-probe/DrawProbe*.cs`）

1. `Dimensions.AddXxx` / `Balloons.AddByTerminator` 的 x,y 是**图纸坐标**（`DrawingView.ViewToSheet` 换算）。
2. 视图里的图元要先包成引用 `view.GetReferenceToGraphicMember2[图元]` 再传。直接传 `DVLine2d`：尺寸值对，但画在图纸左下角；直接传圆弧给 `AddRadius` 一律 `0x80040223`。
3. `DVLine2d.GetStartPoint` 等给的是视图坐标（模型单位、没乘比例）。
4. `SetViewOrientation(视线, 屏幕 x)` 之后必须 `Update()`：不然视图里的图元还是原来的朝向，`AddByFold` 却按新朝向折。视线向量指向看图的人（俯视 = 0,0,1）。
5. 删掉一个模型链接的唯一视图，链接跟着没了（之后 `CO_E_OBJNOTCONNECTED`）。
6. 两点距离默认量斜距，`SetOrientation(水平/竖直)` 改；坐标尺寸 `AddCoordinateOriginEx` + `AddCoordinateEx(基准, 引用, x, y, 0, 关键点, 文字x, 文字y, 0)`。
7. 模板里的刻字引线 `SetTerminator` 改挂失败（`0x80040223`），只能照它的文字新建一条（`AddByTerminator` + `AddVertex` 定文字位置）。
8. `PartsLists.Add(视图, "SK-BOM", 1, 1)` 能出明细表 + 自动序号，默认位置在图纸外，要 `SetOrigin`。
9. **H7**（探针 7 / 7c）：`UseStandardLimitAndFitTolerance = true`、`HoleClassString = "H7"`、`PrimaryToleranceSymbol = "H7"`、`DisplayType = igDimDisplayTypeClassPlusMinus` —— 和人图里的 H7 尺寸属性完全一样，上下偏差天工按标准自己算（Ø6.6 → +0.015/0），图上显示「Ø6.6 H7(+0.015/0)」。**少设 `PrimaryToleranceSymbol` 图上只有 Ø6.6**，偏差也读不出来。
10. 对称公差：`DisplayType = UnitTolerance` + 上 `"0.05"` 下 `"-0.05"`，读回 `±0.05 / ±0.05`；上下偏差：`DisplayType = Tolerance` + 上 `"+0.021"` 下 `"0"`。从 Tolerance 改成 UnitTolerance 偏差会清零。
11. 形位公差框：`FeatureControlFrames.Add(x, y, 0)` 不带引线，(x, y) 是框中心（图纸坐标）；`PrimaryFrame` 用天工编码：`%PO` 位置度、`%PR` 平行度、`%PP` 垂直度（实测画出来是 ⊥）、`%FL` 平面度、`%CO` 同轴度，`%VB` 分格、`%DI` 直径符号，例 `%PO%VB%DI0.03`。带引线：`AddByTerminator(引用, x, y, 0, false)` + `AddVertex`。`SetAlignmentShape(尺寸)` 报 `E_NOINTERFACE`。人图里的框 / 基准 / 粗糙度几乎都**没挂在图元上**（只是摆在旁边），普查只能按位置找最近的图元 / 尺寸。
12. 基准 `DatumFrames.AddByTerminator(边的引用, x, y, 0, false)` + `Datum = "A"`，画出来是公司图里那种圆圈字母。粗糙度 `SurfaceFinishSymbols.AddByTerminator(边的引用, …)` + `RoughnessValue = "3.2"`（最小值跟着变成 3.2，和人图读回的一样）；新建的符号直接读 `SurfaceFinishSymbol` 报 `E_INVALIDARG`，先设再读。

## 完成度怎么量

`tools/drawing-probe/DrawCompare.cs`：同一个零件，人画的图 vs 插件出的图。人图里每个尺寸的数值（线性 / 直径 / 半径 / 倒角；坐标尺寸按串取到串首的距离），在插件图里能不能读出来（直接有同值的尺寸，或同一串坐标尺寸里两个值之差）。

### 基准结果（YF25.07 加工件清单里 40 个带人画工程图的零件，`artifacts/draw-compare-*`）

| 轮次 | 改了什么 | 能读出人图数值的比例（总） | 每张图平均 | ≥90% 的图 |
| --- | --- | --- | --- | --- |
| 3 | 初版（比较器还只比数值） | 76.7% | — | — |
| 4 | 引线文字找空地、倒角标注、Z 朝上的轴测图；比较器改成比"带正负的位置"、读标注文字里的数 | 85.0% | 92.2% | 27/39 |
| 5 | 坐标尺寸挤在一起打折线、螺纹孔写 M 几、盲孔开口那面当主视图、单独的半圆标 R | 84.2% | 91.4% | 26/39 |
| 6 | 折线甩飞的撤回、外棱倒圆的切线不标 | 86.2% | 92.1% | 25/39 |
| 7～11 | 台阶孔加全剖 A-A、球头 / 圆头外端点当落点、只有螺纹线的螺纹孔认 M 几、盲螺纹孔第二行写标准底孔（M4→Ø3.3）、同心圆外圈（法兰外圆）单独标直径、凸台不写贯通、刻线刻字太多时只标外形和孔 | 87.0% | **94.0%** | 29/39（≥85%：35/39，≥80%：37/39） |

总比例被两个大焊接框架（002：196 个、007：110 个要表达的值）拉低：人画它们用了 12～15 个视图（局部放大、剖视），插件只出 3～4 个。

**留出验证集**（没拿来调参数：SK26.01-OK310-02-01A 项目 36 个带人图的零件，含 3 个钣金件、刻度尺）：第 11 轮 89.6%（每张平均 **90.3%**，≥90% 20/36，≥85% 26/36，≥80% 32/36），36/36 全部出图成功。
装配：SK26.01-OK010-05-07A（相机组件，14 行明细）、SK26.01-OK310-02-01A 两个都出了前视 + 俯视 + 外形尺寸 + 轴测序号 + SK-BOM 明细表。
窗口路径（`tools/drawing-probe/FormE2E.cs`，真的 new DrawingForm → LoadActive → 出图）：零件 1 张、装配 + 2 个零件全部成功；装配清单里 MV- / MISUMI 等外购件默认不勾，公司编号件默认勾。

### 公差和粗糙度完成度（0.11.1，`DrawCompare` 的 `TOL` 行和第二行 `RESULT 公差完成度`）

人图里每个带公差的尺寸（值 + 写法；Ø6 +0.012/0 也算 H7）、每格形位公差（符号 + 值，不管 Ø / 基准字母）、每个基准、每个粗糙度符号（Ra 值），插件图里有没有一样的，按个数配对。原来的数值完成度不变。

| 集合 | 数值完成度（每张平均 / ≥90%） | 公差完成度（总 / 每张平均） | 插件加的项里人图也有（准确率） | 规则范围内的人图项（Ø4–8 H7、⌖0.03、Ra3.2）插件对上 |
| --- | --- | --- | --- | --- |
| 调参集，0.11.0（第 11 轮图） | 94.0% / 29/39 | 0/157 = 0% | — | — |
| 调参集，0.11.1（第 13 轮） | **94.0% / 29/39**（没掉） | 27/157 = **17.1%** / 20.5% | 27/46 = 59% | 27/46 = 59% |
| 留出集，0.11.0 | 90.3% / 20/36 | 0/42 = 0% | — | — |
| 留出集，0.11.1 | **90.3% / 20/36**（没掉） | 7/42 = **16.6%** / 13.7% | 7/39 = **18%** | 7/12 = 58% |

* 公差完成度低是因为人图里大部分公差是规律以外的：槽宽 +0.08/+0.03、±0.1 的长度、带基准的平行度 / 垂直度、过盈的 Ø4 -0.02/-0.01（M70-02-313～315）、Ø20 H8 / g6 等，统计里找不到和几何对得上的规律，没做。
* 留出集准确率只有 18%：5 张人图一个公差都没标的（OK310-02-003 / 007 / 015 / 022 两份）插件给 Ø5 光孔加了 H7。Ø5 是四个直径里依据最弱的（全普查 55%，OK310 项目 7/13）。**没拿留出集去改规则**；用户看过后定了 Ø5 保留、Ra3.2 保留（2026-11-03）。
* 规则范围内漏的：一个零件两面都有销孔时人图标两次（02-007、OK310-02-029），插件只在一个视图标一次；02-023 的 Ø8 盲孔在插件选的视图里看不到圆，没标孔也就没加公差。

### 已知要人工补的情况（插件会在「需要人工确认」列写出来）

* 大焊接框架（YF25.07G01-L1-M30-02-002 / 007）：人画 12～15 个视图 + 局部放大，插件 3～4 个视图，尺寸很密（提示「尺寸很密，建议人工整理或加局部视图」）；
* 长的回转件（法兰管 SK26.01-OK310-02-002）：剖视里螺栓孔被剖开，坐标尺寸挤在一起；人习惯在侧视图用 Ø 线性尺寸标各段直径；
* 斜孔（轴线不沿 X/Y/Z）不标位置（提示「有 N 个斜孔」）；
* 0.11.1 起只自动加定位销孔的 H7 + 位置度 Ø0.03 和销孔面 Ra3.2；其它配合公差、±公差、基准、带基准的形位公差、其它面的粗糙度插件不加；
* 人图里有的是改过尺寸文字的（017 的「139」盖在 40 长的模型上），这种对不上不算插件的问题。
