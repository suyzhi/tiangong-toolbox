# 面扫描认孔 · 圆柱面认孔 · 沉孔取「下面的孔径」—— 实测报告（2026-10-05/06）

真机环境：天工CAD **225.03.00.165**（`C:\Program Files\NDS\TianGong 2025`）。
所有原生/界面实测都在**私有桌面 TGWork** 里跑：不打扰用户桌面，也不碰用户文件（夹具是新文档，
落在 `DEV_0.7_授权\artifacts` 下）。

需求（用户原话）：

1. 自动打孔现在要一个一个点孔上边的圆线条，点圆柱面还不认；**点一个充满孔的面，自动识别上面的孔，并把相同的孔归到一类**；
2. **新增点击圆柱面识别孔**；
3. 面上是**沉头孔**时，要**自动识别下面的孔径**，不然下方的孔会配错。

## 1. 事实探针：先把 CAD 接口的事实量清楚（`tools/facescan-probe/`）

命令：`DEV_0.7_授权\tools\run-facescan-probe.ps1`

探针自己新建一块 100×100×20 的板，用生产代码打出圆柱沉孔 Φ11/Φ6.6、平孔 Φ5、锥形沉孔
Φ11 90°/Φ5、孔口倒角 Φ6.6，再立一个 Φ20 高 5 的圆凸台，然后把面拓扑逐条打出来。

| 要量的事 | 量到的结果 | 对实现的影响 |
|---|---|---|
| 面片能不能读出环 | 顶面 7 个环：6 个内环（`IsOuterLoop=False`，每个 1 条整圆边）+ 1 个外环（4 条直边） | 孔口＝内环上的整圆，用它当第一道筛 |
| 圆凸台的底圆在哪 | **也长在内环上**（环#1 就是 Φ20 凸台底圆） | 只按"内环"筛会把凸台当成孔 → 必须再加一道"壁在哪一侧"的判据 |
| `Edge.IsClosed` | 整圆 True，直线/圆弧 False | 用来只收整圆 |
| `Edge.GetFaces` | **传 null 数组会抛 NullReference**，传空数组才正常 | 找"孔口旁边的壁面"要用空数组调用 |
| 沉孔口的下面有没有更小的同轴圆 | 有：Φ11 沉孔 → Φ6.6@z=4（沉孔底）、Φ6.6@z=-10（出口）；锥沉 Φ11 → Φ5@z=7；倒角孔口 Φ7.6 → Φ6.6@z=9.5 | 沉孔识别就按"同轴 + 更小"取最小那个 |
| `Face.GetRange` | 返回 **3D 包围盒**（沉孔壁 (14.5,14.5,4)..(25.5,25.5,10)） | 用它判"壁在材料的哪一侧"，从而排除凸台 |
| `Body.get_FacesByRay` | 是**整条直线**的查询：点在材料内/外返回一样的面 | 内外判定这条思路作废（一度想用它判凸台） |
| 圆柱面 `IsParamReversed` | 沉孔壁 True、Φ6.6 孔壁 True、Φ20 凸台外壁 **False** | 点圆柱面认孔时用它排除凸台 |
| `Face.GetNormal` | 一直 `E_INVALIDARG`（这个版本上用不了） | 所以没走"取面上法向"那条路，改用 `IsParamReversed`（原生回归日志里那几行 `WALL … GetNormal 失败` 就是这个诊断，不是断言失败） |

36 条断言里包含：

* 面扫描：**5 个孔、跳过 1 个（Φ20 凸台底圆）**；按孔径归成 3 类；Φ6.6 那类 3 个（2 沉孔 + 1 倒角孔口）；
  **没有任何孔按 Φ11 配做**；
* 点沉孔的孔口圆边（Φ11）读出来也是 Φ6.6（不是 Φ11）；
* 点圆柱面：沉孔壁（Φ11 圆柱）→ Φ6.6；Φ6.6 孔壁 → Φ6.6；螺纹孔壁 → Φ4.917；锥形沉孔的圆锥面 → Φ5；
* 点 Φ20 凸台外壁 / 凸台底圆 → 明确拒绝（报"这是圆凸台的外壁/底圆，不是孔"）；
* 往 B 板配做：5 个孔全部打出，**切除体积 = 3×M6 螺纹孔 + 2×M6 沉孔**（与理论值差 <3%）；
  如果按孔口 Φ11 配，会变成 M10 螺纹孔（Φ8.376），体积是现在的 2.9 倍 —— 这一步把"配错"钉死。

## 6. 已知取舍（都是"宁可多认，不要漏认"这一侧）

| 情况 | 行为 |
|---|---|
| 找不到孔口旁边的壁面 / 面片外法向读不出来 / 壁几乎不偏（<0.5mm） | 一律**按孔处理**（多认一个让用户在预览里看见，不静默漏孔） |
| 点圆柱面认孔时的凸台判断 | 用 `IsParamReversed` 约定（4 张面实测）；圆锥面/圆环面不做这个判断 |
| 读不到面的环信息（老版本 CAD） | 退化成"面上的所有圆边"，并在状态栏提示"可能混进轮廓圆角或凸台" |
| 孔口倒角 vs 锥形沉孔的叫法 | 壁是圆锥面时按半增量分：≥1mm 叫锥形沉孔，<1mm 叫孔口倒角（只影响文案） |
