# 0.8.5 交接（2026-10-24）：一轮"正常人怎么用"的实测 + 修复（50 处）

用户原话：「插件在这里无法打孔，说是已经有一个孔自动跳过，请找出原因并修复。/loop 继续实测插件，找出正常人使用时会遇到的所有问题并修复，高复杂度问题至少找出50个，制作好后更新版本号并激活。」
中途追加：「打开插件后无法使用天工自带的右键选遮挡面的功能……我需要你加上右键选遮挡面的功能。」（= 第 34 条）

## 一、截图那个问题的根因（第 1 条）

`HoleSpots.At` 只看"孔心是否在某个圆的轴线上"，不看圆在轴向哪里。截图里灰色块顶面要打的孔，正下方底面有一个同轴盲孔 → 被当成"这个位置已经有孔、已跳过"。
同一天 19:39 的 panel.log 也对得上：02-23.par 2 个孔，先进原位编辑 7.9 秒，结果一个都没打。
改法：孔口那一圈必须在打孔面上（轴向 < 0.2mm）才算已有孔；从哪面打穿的通孔照样在打孔面上有孔口，照样认得出。
真机 `CoaxialE2E`：底面盲孔正上方打通孔 / 盲孔 CAD 都接受（CAD 并不拒绝同轴孔）；顶面真有孔口的、底面打穿的通孔仍判"本来就有孔"。

## 四、没做 / 下次注意

* 右键 QuickPick：真机确认了天工接受 seLocateQuickPick（S8），弹出的遮挡面列表要用户自己点一下看效果（私有桌面里没做鼠标点弹窗的测试）。
* 深层子装配里保持关联打孔：每批进原位 ~15 秒、退出 ~14 秒（天工自身耗时，日志 15:23 / 15:25 那两批），没动。
* 钣金件（.psm）仍不支持自动打孔 / 排孔，只把提示说对了（第 27 条）。
* 撤销打孔仍不删插件建的基准面（0.7.14 遗留；基准面可能被后面几批共用，删了会坏孔）。
* 「同步孔位」仍要把整个装配的零件加载一遍才能找插件关联的孔。
