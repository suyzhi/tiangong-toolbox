# 0.9.1 交接（2026-10-25）：自动打孔 —— 点面按页面定、不自动翻页；点面连腰孔一起认

用户原话：「现在在参考孔页面，点面应该可以自动识别面上的孔，但是不要选完孔之后自动跳转到打孔面页面，然后点面时自动识别面上的孔是参考孔页面的默认功能，不需要添加开关，用户切换到打孔面之后默认是选择面，而不是选择面上的孔。还有一个bug就是有时候选面，无法识别到面上所有的孔，这是一个bug。请修复，然后更新0.9.1版本号，提交并推送，安装并激活。」

## 一、点平面的意思按页面定（`src/AutoHoleForm.cs`）

| 在哪一步 | 点平面 | 按住 Ctrl 点平面 |
| --- | --- | --- |
| ① 参考孔 | 认面上的孔（圆孔 + 腰孔）当参考；**没认出孔也不当打孔面**，状态栏说「到打孔面那一步再点它」 | 当打孔面 |
| ② 打孔面 / ③ 孔规格 / ④ 预览 | 当打孔面（面上原有的孔不认）；之前从这张面认进来的参考孔/腰孔撤掉 | 认面上的孔 |

* 点孔口圆边、孔内壁、腰孔圆弧：哪一页都是加/取消参考，和原来一样。
* **点了以后不再自动翻页**（0.9.0 点了面跳「打孔面」、点了孔跳「参考孔」）；新加的项照旧闪一下，左侧步骤栏计数照旧变。
* 去掉「点平面时自动识别面上的孔」开关；`autohole.tsv` 里老版本存的 `scanFace` 不再读（用户机器上是 0），只剩 `keepLink`。
* 0.8.5 的「已选参考孔投得到空位的带孔面 = 打孔面」（`FreeSpots`）只留给**打开窗口前在天工里预先选好的对象**（`PlanePick.Auto`）。
  鼠标点不再走它 —— 0.9.0 里它就是「在参考孔页点第二张带孔的面，结果面上的孔一个没认、还被带到打孔面页」的原因。

## 二、「点面有时认不全面上的孔」

先量再改：`tools/hole-feature-probe/FaceScanAudit.cs` 在用户 `H:\桌面\YF25.07\焊接台车` 最近改过的 30 个零件**副本**上逐张平面比对
`HoleScanCad.ScanFace` 认出的孔和面上实际的孔口（只读、不存盘）。

| 量到的 | 数量 |
| --- | --- |
| 平面 / 有孔口的面 | 1029 / 227 |
| 圆孔（内环整圆）漏认 | 0（只有 1 个 Φ24 圆环面倒圆，确实不是孔） |
| **腰孔（两段同半径圆弧 + 两条直边的内环）** | **7 条，点面一条都不认**（0.9.1 后 7/7 认出） |
| 圆角矩形窗口（四角 R3 / R10 圆弧 + 四条直边，如 -02-17 的 40×250、22×270 开口） | 约 50 个、200 段圆弧；第一轮审计误算成"单段圆弧漏认"，第二轮按环的组成分开 —— 是窗口不是孔，不认是对的 |
| 外环上的圆弧（孔切到面的边、孔底圆盘面） | 不是"面上的孔"，不算 |
| 被拆成几张的共面面 | 0 |

修了：
结论：圆孔几何识别本身没漏；用户感到"认不全"，主要是 0.9.0 在参考孔页点第二张带孔面时被当成打孔面（一个孔都没认、还跳了页，第一节已改），其次是腰孔不认。

1. **点面连腰孔一起认**：`HoleScanCad.ScanFaceSlots`（判据同点圆弧认腰孔：内环 = 两段同半径圆弧 + 两条直边；圆弧那头的壁往材料外凸的是腰形凸台，跳过）。
   认进来的腰孔在列表计数里写「腰孔 N」，目标件上配同样的腰孔（通切）。参考孔页标题行新增「去掉腰孔」（圆孔不动；单条腰孔再点一次它一头的圆弧 = 取消）。
2. **判"孔还是凸台"用孔口自己旁边的壁**：原来按"同轴同径"在整个实体里找第一张壁面、不看轴向位置 —— 方管/型材上下两壁打穿的孔、两头同径孔的轴类件，
   会找到对面那个孔的壁（在这张面外侧）而把孔判成凸台跳过。现在先用孔口那条边自己相邻的壁面；退回按同轴找时要求就是这个圆（轴向偏 ≤ 0.01mm）。
3. **两段半圆拼整圆的容差**：圆心 0.001mm → 0.01mm、半径 0.001 → 0.005mm（导入件拆开的半圆常有这点误差）。
4. 每次点面认孔在 panel.log 记一行 `AutoHoleFaceScan`（圆孔 / 腰孔 / 判为凸台个数），下次现场再说"认不全"能直接看。
