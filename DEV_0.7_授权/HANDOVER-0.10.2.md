## 三、没做 / 已知问题

* **高 DPI**：TianGong.exe 是 per-monitor DPI 感知（`GetProcessDpiAwareness`=2，DpiCheck 实测）。插件窗口没有 AutoScaleMode、尺寸写死像素、字体按磅 → 125% / 150% 屏幕上字变大框不变。本机 100%，改显示缩放会打扰用户，**没盲改**；要先在调了缩放的同事笔记本上看效果。
* 葫芦孔 / 两头不一样大的长孔：只提示，不配。
* SolidWorks 工程图：天工打不开，转换器只能说清楚。
* `LinkSyncE2E` 剩下的 FAIL 是 0.7.3 时代断言（插件关联 + 单孔特征），实际原生关联孔都跟过去了；探针没改。
* 测试工具踩坑（写给下一轮）：
  * 转换器 / 测试自己 `CreateInstance` 的天工（父 = svchost）会被原队列当成"用户的天工"中止任务 → 用 `run-cad-queue-convert.ps1`（放过 DCOM 拉起的、每个任务结束收掉）。**要用 powershell.exe 5 跑**，pwsh 下会中断。
  * 被中止的任务可能留下一个 `/automation -Embedding` 的天工，让后面的任务一直"等用户的天工关闭"：看命令行确认是 DCOM 拉起的再收。
  * 天工上次异常退出后，下次启动会弹「终止日志」对话框，卡住探针到超时 → 重跑一次。
  * 队列脚本把输出目录作为 exe 的第一个参数：`PanelTests.exe --table-cad` 这类要用 `.cmd` 包一层。
  * 中文 .ps1 / 探针源码：PowerShell 5 读 .ps1 要带 BOM；heredoc 里写 C# 字符串的 `\r\n` 会被吃掉（用 Edit 工具）。
  * 大装配探针别逐孔问 CAD（LinkedDrillE2E 原来 3595 个孔半小时挑不完，已加包围盒预筛）。
