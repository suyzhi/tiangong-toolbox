# 0.8.3 交接（2026-10-23）：一轮找 bug + 降复杂度

用户原话：「找出至少50个使用上会造成致命性问题或需要大量时间停下来修复插件的bug并修复，并降低算法复杂度。做完好安装并激活，然后提交并推送。需要使用真实文件实测，真实文件需要创建副本备份后再实测。」

逐个模块读代码找出来的问题，按「会把天工 / 插件搞挂、会丢数据、会让人停下来收拾」排。每条都改了；真机能测的都在副本上测过（见第三节）。

## 四、没做 / 下次注意

* **带零件间链接的零件上「批量排孔」建不成阵列**（`AddByRectangular` 报 E_FAIL，自动退回逐个打孔，孔都对）。0.8.2 在装配里打也一样（`LinkedPatternE2E` 新旧对照），是老问题，没查原因。
* #25（批量排孔对带链接零件进原位）：合成件上旧版在装配里也打得上，0.7.11 现场那种 0x80010108 没在副本上复现；按自动打孔的做法对齐，副本上新版同样通过。
* 授权「时间回调」判定的高水位只增不减：系统时间被错调到未来、插件跑过一次，改回正确时间后会一直报"时间被回调"，重新激活也清不掉（`LicenseStore.SaveStamp` 取最大值）。属于防破解设计，改它要先和用户商量，没动。
* 撤销打孔仍然不删打孔建的基准面（0.7.14 遗留）。
