# 0.7.14 交接（2026-10-22）：打孔、撤销后再打，一直报「建不出打孔基准面」

用户截图：自动打孔，参考孔 `支撑条.par:8` 上 Φ6.6 ×2（Φ11 沉孔），打孔面 `YF25.07G01-L1-M30-02-23.par:1`（在 `支撑板.asm:1` 里）「平面 533」，
弹「无法在所选面上建立打孔基准面（位置/朝向都不对）。请重新点一次这个面再打。」

全部在**副本**上做（scratchpad 里整个 `H:\桌面\YF25.07\焊接台车` 的副本，原文件没动）。

## 一、现场日志（0.7.13，2026-10-22 18:59～19:06）

* 同一张面 7 次失败，中间 19:00:51 成功过一次；18:33 在同一个零件上打过 6 个孔。
* 每次失败都是：进原位 → 一次 `AutoHolePlaneDelete` E_INVALIDARG → 抛「位置/朝向都不对」。
* 哪一条验收没过**看不到**：`AutoHoleWriter.Info()` 只写控制台。
* 19:01:10 用户按提示重新点这张面，被「这个面已经选过了」挡回去。

## 二、副本上查明的

| 步骤 | 结果 |
| --- | --- |
| 新开的副本，同一张面、同一组孔，保持关联 / 不保持关联 | 都打上（`artifacts/e2e-support-0223`） |
| 窗口 A 先点好面；窗口 B 在同一零件上打 + 撤销；A 再打 | **复现**：「位置/朝向都不对」；A 重新点面再打也一样（`artifacts/e2e-support-0223-stale`） |
| 失败时的诊断（新加的日志） | 面(局部) (0, 1.45, 0) 法向 (1,0,0)、外法向 (-1,0,0)：打孔面就在零件基准面 x=0 上；③ 用面片建的基准面「位置偏 0mm，法向·外法向 = 0」= 读根点/法向都抛异常（死对象），删也删不掉 |

根因：`FindOrCreatePlane` ② 找共面基准面**只取第一张**。这里第一张是零件基准面（法向扎进材料，不能用），
上一次打孔建的那张（重合、朝外）撤销后还留着，排在后面却没被看；于是去 ③ 拿面片再建一张，
面上已经有重合基准面时天工返回死对象。④（平行基准面 + 偏移）因为偏移量是 0 也跳过。
