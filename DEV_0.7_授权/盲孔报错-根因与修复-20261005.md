# 盲孔报错根因与修复（2026-10-05）

> 现象：装配体里打**盲孔**一直失败（重试 6 次后弹「打孔失败：CAD 没能在孔心上建出孔特征」），
> 同一张面、同一个孔心改打**贯通孔**就成功。

## 一、结论（一句话）

打孔基准面建错了地方 —— **位置偏了 40mm（整块在材料外面）**，而且**法向扎进材料**。
盲孔只能在平面上切固定长度，切在空气里就建不出特征；贯通孔的圆柱轴线不受平面位置影响，
所以"看起来正常"。CAD 接口最终只回一个含糊的 COM 错误（RPC_E_DISCONNECTED 0x80010108 /
CO_E_OBJNOTREG 0x800401FB），把现象指向了"这个位置已经有孔了"，属于误诊。

## 二、复现（用户模型的副本 + 生产代码路径）

复现环境：把 `H:\桌面\测试\YF25.07兼容小车托盘部分\` 整个复制到工作目录，
用探针打开**副本**装配，取 `YF25.07兼容小车托盘铝板.par` 的上表面（面积 1.18 m²，
零件局部 y=+20mm），调用的就是生产代码 `AutoHoleWriter.DrillRequests`。

| 同一孔心 | 旧版（0.7.1 现状） | 修复后 |
|---|---|---|
| 盲孔 Φ2.46 深 10mm | ❌ 0x80010108（复现 2 次） | ✅ Created=1 |
| 贯通孔 Φ2.46 | ✅ | ✅ |

旧版建出来的基准面：**root=(0, -0.02, 0)**，所选面在 **y=+0.02** → 偏 **40mm**，
整块在材料外（零件料厚 20mm：体包围盒 (-1.097, 0, -0.478)…(0.147, 0.02, 0.478)）。

## 三、根因：两条隐含约束，旧代码一条都没验

### 1) 位置：基准面必须在所选面那张平面上

`FindOrCreatePlane` 的"平行基准面 + 偏移"分支**只比法向、不比位置**。本零件的平面清单：

| 基准面 | 根点 | 法向 |
|---|---|---|
| RefPlane_1 | (0,0,0) | (0,0,1) |
| RefPlane_2 | (0,0,0) | (1,0,0) |
| RefPlane_3 | (0,0,0) | **(0,-1,0)** |

上表面 y=+0.02 与 RefPlane_3 平行，偏移量 20mm。实测（`SideProbe sides`）：

```
side=igNormalSide        -> root=(0, -0.02, 0) normal=(0,-1,0)   与目标面轴向偏差 = 40 mm
side=igReverseNormalSide -> root=(0,  0.02, 0) normal=(0,-1,0)   与目标面轴向偏差 =  0 mm
```

**两张候选面的法向一模一样**，所以"法向对就收工"的判断必然选中先试的那张，
而它正好是镜像位置。这就是"盲孔老报错、贯通孔就可以"的来源：贯通孔切的是轴线，
基准面偏 40mm 照样能穿过材料。

### 2) 朝向：基准面的法向必须背对材料

面片参数反向时（本例上表面 `IsParamReversed=True`，`GetPlaneData` 给的法向 (0,-1,0)
是**扎进材料**的方向），照它建出来的基准面朝向也是反的。实测（`SeqProbe`，每次都换全新副本）：

| 场景 | 基准面 | 结果 |
|---|---|---|
| 上表面、基准面 root=(0,0.02,0) normal=(0,-1,0)（扎进材料） | 位置精确 | ❌ 盲孔失败，**贯通孔也失败** |
| 上表面、基准面 root=(-0.475,0.02,0) normal=(0,1,0)（朝外） | 位置精确 | ✅ 盲孔成功 |
| 下表面、基准面 root=(0,0,0) normal=(0,-1,0)（朝外） | 位置精确 | ✅ 盲孔成功 |

即：**位置与朝向缺一不可**。

### 3) 顺带确认的 API 事实

- `RefPlanes.AddParallelByDistance(ParentPlane, Distance, NormalSide, Pivot, PivotOrigin, Local, FlipNormal)`
  的 `FlipNormal` 对"平行面 + 偏移"建法**实测无效**（传 true 建出来的面法向不变），不能用来纠朝向。
- `RefPlanes.AddParallelByDistance(面片, 0, igNormalSide, …)` 建出来的面：
  位置偏差 0mm、法向与面片外法向点积 = 1；`igNormalSide`/`igReverseNormalSide`/`FlipNormal` 四种组合结果相同。
  → 需要"位置 + 朝外"的基准面时，**直接用面片建**最稳。
- `Face.IsParamReversed` 在本零件 17 张平面面上逐个核对，与几何朝向**全部吻合**，
  是判定外法向的可靠依据（外法向 = IsParamReversed ? -几何法向 : 几何法向）。
- 更早的实测已经记录过"一侧失败后换另一侧会抛 CO_E_*"（`recipe-spike-01.stdout.txt:75-77`），
  与本轮看到的错误族一致 —— 那是**失败之后**的连锁反应，不是独立故障。

## 四、修复（`DEV_0.7_授权/src/AutoHoleCad.cs`）

1. 基准面准入改成两个硬条件：
   - `PlaneOn(plane, fpt, fnv)`：与所选面平行 **且** 落在那张平面上（0.001mm 容差）；
   - `PlaneFacesOut(plane, outward)`：法向背对材料（`outward` 由 `Face.IsParamReversed` 换算）。
2. 选面顺序改为：① 缓存（活 + 位置 + 朝向）→ ② 已有共面基准面（同条件）→
   **③ 直接用面片建**（距离 0：位置天然精确、法向由 CAD 按面片朝向给）→
   ④ 平行面 + 偏移（兜底：按 `(fpt-r0)·n` 的符号算方向，按位置 + 朝向验收，不合格的当场 `Delete()`）。
   缓存命中不再只看"对象活着"，避免了上一版建偏的那张被一直复用（"老是报错"）。
3. 失败信息：盲孔失败时补一句"请确认深度小于料厚、孔底还在材料里"，位置也不对时直接给出
   "基准面偏离孔心 X mm"的诊断，不再一律赖"已经有孔了"。

## 七、补充根因：打完第一批孔后，用户点的面片会失效（第二次打孔）

实测（`SeqProbe blind-twice`，同一张面连着打两个盲孔）：

- 第 1 个孔：`target.Face.IsParamReversed` 读得到（True）→ 外法向 +Y → 基准面
  root=(-0.475,0.02,0)、法向 (0,1,0)、离面 0mm → ✅ Created=1。
- 第 2 个孔（换孔心）：`target.Face.IsParamReversed` **直接抛 E_FAIL**（面片被建模过程作废了）。
  这时如果照旧退回"几何法向"，对反向面正好是**反的答案**（-Y）：
  零件里那张**好基准面**（+Y）会被判成"朝向不对"而弃用，转而新建一张位置对、朝向反的面
  （root=(0,0.02,0)、法向 (0,-1,0)）→ ❌ 打孔失败。

修法（三级取外法向 + 用新面片建面）：

1. 问目标面片 `IsParamReversed`；
2. 读不到就按平面数据在**实体现有面**里找回同一张面（`FindModelFace`：平行 + 共面）再问一次；
3. 还不行就用这个位置**第一次问到的答案**（`OutwardCache`）；
4. 建基准面时也用找回来的那张新面片（失效的面片建不出来）。

修完这一条，"同一张面连着打多个孔"也过了（见下表 blind-twice）。
