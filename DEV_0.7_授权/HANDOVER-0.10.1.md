## 四、没做 / 限制

* 打孔基准面在「撤销本次打孔」后仍留在特征树里（0.7.14 遗留）。删基准面可能连带删掉用户后来挂在它上面的特征，没敢动。
* 配孔检查剩下的大多是外购件内部（导轨滑块、把手、气缸、传感器的建模细节）。分不出"外购件"，没有一刀切；同一处已合成一条。
* 批量改名：设计管理器列某个父文件的链接时只要一个链接读不出就整批不改（安全优先），没在断链文件上验证过。
* 高 DPI（125% / 150%）下的排版没有实测（本机 96 DPI）。
