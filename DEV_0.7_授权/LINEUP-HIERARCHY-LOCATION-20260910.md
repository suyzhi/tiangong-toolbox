# Lineup 层级与位置图：第一版开发记录

本次在 DEV_0.4 内扩展现有 Lineup 模块。没有替换已经注册的 CAD 插件 DLL，没有修改生产装配或生产 WPS 工作簿。改动前源代码、测试代码及源文件 SHA-256 保存在 `../artifacts/lineup-hierarchy-20260910-before/`。

## 已实现

- 新增大按钮：上方插入、下方插入、上移、下移、气缸归阀片、阀片归阀岛、查看层级、导出位置图。
- 多选气缸指定同一阀片；关系按记录 ID 保存。一片阀控制多个气缸时生成 `C01-1/C01-2`，H/W/M 编号同步。编号冲突阻止本次保存，操作可撤销。
- 阀片移到其他阀岛时，已建立关系的气缸、传感器一起更新编号及所属阀岛。旧清单不会仅凭相似编号自动推断控制关系，需要首次批量归类。
- 层级树双击可跳到相应记录；表格增加所属上级列。筛选内移动行保留隐藏记录的位置；列排序状态下阻止移动，避免显示顺序与保存顺序不一致。
- 从当前 CAD 视角导出干净底图、逐个高亮图、`locations.xml` 和可检查的 CSV。坐标为相对完整图片的 0～1 比例，同时保留 Lineup ID、编号、型号和识别状态。
- 优先识别双色高亮；本机 CAD 导出器将高亮画成黑轮廓，因此加入两次高亮与底图的稳定差分。坐标取实际差分像素，不取可能落在空处的包围盒中心。空白截图会重试，截图前后变化则标为待定位。
- WPS 导入脚本在新工作簿中生成图片、红色可编辑箭头和编号/型号单元格。箭头尾部位于零件坐标，头部指向编号单元格。已有输出文件不会覆盖。
- VBA 模块提供整包导入新工作表，以及选择已插入图片、按编号指定空单元格生成箭头两种入口。

## 试用入口

1. 在天工打开独立装配副本，再运行 `../artifacts/lineup-hierarchy-20260910-build/LineupPreview.exe`。该程序是开发预览入口，调用同一 Lineup 模块，不改变插件注册。请勿同时打开两个清单编辑器编辑同一装配。清单仍会自动保存到装配旁的 `.lineup.xml`。
2. 创建阀岛/阀片后，多选气缸点击“气缸 → 阀片”；需要换岛时选择阀片点击“阀片 → 阀岛”。
3. 先在 CAD 调整好视角，再选择本张图要标注的清单行，点击“导出位置图”。导出时保持 CAD 视角不动。每个视角单独生成一包。
4. 无需 VBA 的已测入口：

```powershell
powershell.exe -NoProfile -File "DEV_0.4_插件框架/tools/Import-LineupLocations.ps1" -PackageDirectory "位置图包完整路径" -OutputFile "新工作簿完整路径.xlsx"
```

5. 有 VBA 环境时，把 `tools/LineupLocations.bas` 导入 WPS VBA 工程。`ImportLineupLocationPackage` 导入整张新工作表；`LinkSelectedPictureToCell` 使用已插入的完整图片，输入编号后指定两个空白单元格中的左格。图片不能裁剪或旋转；编号写左格，型号写右格。箭头生成后再移动或缩放图片，需要重新生成箭头。

## 未完成的验收与边界

- 本次实际位置识别对象为简单独立零件，尚未在用户的大型气缸/传感器装配上验证遮挡、透明件、嵌套子装配及大量标注。
- 第一版使用用户当前视角；尚未实现自动寻找最佳视角、多视图分配和密集箭头避让。不可见零件需要换视角另出一图。
- VBA 代码已提供，但 WPS VBA 的选图、选单元格和宏交互尚未实际验收。当前已测的可用替代入口是 PowerShell 导入脚本。
- 箭头当前是独立图形，不会在生成后继续自动跟踪图片移动、裁剪或缩放。选图宏仅在生成时按当前图片尺寸计算。
- 尚未安装替换正式 CAD 插件，也未把这些测试称为大型生产装配最终验收。
- WPS 的 PDF 预览导出在本机未产生可供 Poppler 读取的标准 PDF，因此改用 WPS 原生 CopyPicture 检查；该 PDF 不作为交付文件。
